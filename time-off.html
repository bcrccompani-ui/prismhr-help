Approve or Deny PTO Requests

After receiving notification of an employee’s request, managers can approve or deny the request from PrismHR.

  1. Log in to PrismHR.

  2. Open Approvals Pending (found in the Client menu under Client|Action).

Note: Note: Users might find it handy to save the form as a favorite so it is always easily accessible, or search for it when it is needed rather than using the menu.

[Image: screenshot]

  1. Open the request by clicking Leave Request.

  2. Review the details of the request and then click the appropriate button:

  • Approve: Approve the request. The request approval clears from the Approvals Pending form, and the employee receives notification that their request was approved.

  • Deny: Deny the request. You need to enter a reason for the denial and then press Tab, then you can select the checkbox and click the final Deny button. The reason you enter might be included in the e‑mail notification to the employee.

  • Close: Return to the Approvals Pending form.

View or Cancel PTO Requests

Source: https://tech-docs.prismhr.com/SP_help/Content/PD/PTO/ESS/View_Cancel_PTO_Requests.htm Path: PD/PTO/ESS/View_Cancel_PTO_Requests.htm

View or Cancel PTO Requests

You can review and make changes to employees’ time off (PTO) requests in the Planned Time Off Requests form.

Important! The system circumvents leave approval security configurations and workflows for users with access to this form, which can result in unexpected behavior.

Please note the following security used by this form:

  • Users with the PTO Administrator H/R Role and access to Manage Planned Time Off Requests can update leave for all employees in the client regardless of their Data Security access or the assigned PTO Approver.

  • Users without the PTO Administrator H/R Role and with access to Manage Planned Time Off Requests can update leave only for employees where the user has access via Data Security, regardless of the assigned PTO Approver.

Viewing Planned Time Off Requests

The requests in the list are for employees at the active client who submitted them through Employee Portal (EP).

To view the planned time off requests for the client, do the following:

  1. Go to the Planned Time Off Requests form. When the form opens, the following message displays, “Please wait while we get the leave requests.” (Note: This form defaults to the Display Pending and Display Approved options, so the system will display those entries.)

  2. Use the filters at the top of the form to specify which requests to display.

  3. If there is more than one page of results, the total number of pages displays above the results, and the Next Page and Previous Page buttons display at the bottom of the page. Long comments or multiple vouchers display additional lines on the form.

Note: Note: Each page displays up to 20 leave requests.

Making Changes to an Employee’s Time Off

To make changes to an employee’s time off, you can:

  • Set an Approved request to Cancelled.

  • Set an Approved request to Paid. If you select Paid, then it is removed from this list and from any payrolls.

  • A yellow indicator [Image: screenshot] displays next to the start date if it is before the period end date of the last completed scheduled payroll batch for the employee’s pay group. The system considers it to be a “back dated” request.

Instead, the system displays the approver from the approval policy.
  • If a manager cancels a Time Off request on this form and then the request is approved later on this form, the leave request indicator in the Summary Time Sheet Entry form is restored and the employee’s EP Time Off landing page displays the approved request.
  • The system does not record the user who approves a Time Off request as the leave approver in the Planned Time Off Requests form. Instead, the system displays the approver from the approval policy. | Cancelled | The Time Off request is cancelled. This cancels an employee’s approved Time Off in the EP that occurs in the future. > Note: Note the following: - Canceling approved Time Off that occurs in the future stops the Time Off from being applied to the timesheet when it is created. - Canceling approved and applied Time Off on the current timesheet does not remove the indicator and the hours should be manually adjusted in the timesheet. |
  • Canceling approved Time Off that occurs in the future stops the Time Off from being applied to the timesheet when it is created.
  • Canceling approved and applied Time Off on the current timesheet does not remove the indicator and the hours should be manually adjusted in the timesheet. | Paid | The Time Off request was previously paid and the employee’s Time Off register was updated. Only service providers can select this option. Note: This status removes the leave request indicator from the timesheet and removes the request from the employee’s EP or Employee Portal (EP) Time Off landing page. Users can be set to see all employees at the client that they are allowed to access by giving them the PTO Administrator account management role in the Users form. Note that if you want a user to be able to view requests but not approve them, the user role must have Inquiry permission for Planned Time Off Requests.

Tracking Absences

Source: https://tech-docs.prismhr.com/SP_help/Content/PD/PTO/FrontMatter/PTO_UG_How_System_Tracks_Absences.htm Path: PD/PTO/FrontMatter/PTO_UG_How_System_Tracks_Absences.htm

Tracking Absences

PrismHR tracks paid absences automatically during regular payroll processing. Users can manually enter unpaid absences and review them at any time on a number of different absence reports.

  1. During Payroll calculation the system reviews the Pay Code record for each Pay Code entered on an employee’s timesheet.

  2. If the Pay Code on the timesheet is associated with a Paid Absence Code and Updates Time Off Register is checked, the system updates the employee’s Time Off Register with the hours from the timesheet, deducting from the employee’s available Time Off balance.

  3. If the number of Time Off hours exceeds the employee’s available Time Off balance, the system alerts the payroll processor with a warning, but allows processing to continue.

  4. You can manually enter absences that are unpaid and other adjustments to the employee’s Time Off Register in the Time Off Adjustments form.

Note: Unpaid absences do not affect the Employee’s Time Off register totals, but they might be referenced in various reports and inquiries.

Learning About Time Off Plans

Source: https://tech-docs.prismhr.com/SP_help/Content/PD/PTO/FrontMatter/PTO_UG_PTO_Benefit_Plans.htm Path: PD/PTO/FrontMatter/PTO_UG_PTO_Benefit_Plans.htm

Learning About Time Off Plans

A Time Off plan, or absence plan, determines how much paid time off an employee can accrue. The employee Time Off register is the place where the system keeps track of how much has been accrued and taken by the employee.

The Time Off plan establishes limits on the amount of paid time off that may be earned. This is the number of hours that can be carried over from one plan period to the next, or the number of hours the employee can earn. Clients often have more than one Time Off plan, for example:

  • Vacation

  • Sick

  • Personal

  • Other plan types that represent time accrued and taken according to the client’s policy

You can also have more than one type of benefit plan, such as multiple vacation plans. The Benefit Plan is assigned to an employee at enrollment.

Note: Note: The Time Off accrual schedule indicates when employees accrue paid time off. The Time Off Plan indicates how much paid time off employees accrue.

Archiving Mass Employee Time Off Registers

Use this feature to archive Time Off registers for multiple employees at once. For example:

[Image: screenshot]

Note: The Mass Archive Employee Time Off Registers form is only available for service providers.

To perform a mass archive of employee Time Off registers:

  1. Go to the Mass Archive Employee Time Off Registers form on the Time Off Adjustments and Maintenance|Maintenance menu and complete the following fields:

Field — Description

Accrual Schedule — Enter or select the Time Off accrual schedule for your active client. If you select this field, the Select Accrual Schedule form displays. You can either select from the list that displays or search for a specific accrual schedule by entering it in the field. After you select one of the accrual schedules, the form closes and it displays in the Accrual Schedule field back in the Mass Archive Employee Time Off Registers form. Note: The list of accrual schedules that display are the same as those available to the client in the Time Off Type Code field on the Time Off Types form.

Time Off Plan — Enter or select the Time Off plan for your active client. If you select this field, the Select Time Off Plans form displays. You can either select from the list that displays or search for a specific Time Off plan by entering it in the field. After you select one of the Time Off plans, the form closes and it displays in the Time Off Plan field back in the Mass Archive Employee Time Off Registers form. Note: The list of Time Off plans that display are the same as those available to the client in the Plan Code field on the Time Off Plans form.

  1. Select Find Employees. In the employee list that displays, you can Select All employees or make individual selections from the list.

Note: If you select a different Time Off type or Time Off plan after selecting Find Employees, the following message displays, “Selecting a new Time Off Type or Time Off Plan will clear the current list of employees. Do you wish to continue?” Click Yes to clear the list of employees or No to cancel.

  1. Click Archive Registers. A confirmation message displays, “You are about to archive <number> employee Time Off registers and all associated records and enrollments. Do you want to continue?” Select one of the following:

  • Yes: Archives all Time Off registers for the selected employees. (Note: After you make this selection, the Employee Time Off Register form no longer contains any evidence of this record.)

  • No: Cancels the archive and returns to the form where the Accrual Schedule and Time Off Plan selections still display.

Note: Note the following before clicking Archive Registers:

  • Archiving an employee’s Time Off register moves this employee’s posted record of all accrued, used, and carryover Time Off for employees in this accrual schedule. (The employees will no longer be enrolled in this Accrual Schedule and Time Off Plan.)

  • Performing a mass archive does not include Global PTO.

  • If you click Archive Registers without selecting the Accrual Schedule or Time Off plan, the following message displays, “Registers can only be archived after selecting employees. Select an Accrual Schedule and Time Off Plan to list employees.”

  • If you click Archive Registers without selecting an employee, the following message displays, “Select at least one employee register to archive.”

Recalculating Time Off Accruals

Source: https://tech-docs.prismhr.com/SP_help/Content/PD/PTO/Work-Center/PTO_Accrual_Recalculation_Form.htm Path: PD/PTO/Work-Center/PTO_Accrual_Recalculation_Form.htm

Recalculating Time Off Accruals

You can use the Time Off Accrual Recalculation form to recalculate time off accruals for the selected Time Off Type, Accrual Schedule, and Time Off Plan for the current plan year. (The date range automatically adjusts for each employee based on the year-end date in their register.)

Important! The Time Off Accrual Recalculation form does not work with Global PTO.

The Time Off Accrual Recalculation form is helpful in case the initial setup was incorrect or you need to make a bulk adjustment. However, you must first update the Time Off plan/register for a time off recalculation to appear. For example:

[Image: screenshot]

Note: This feature is only available for service providers.

Important! At this time, a note displays stating that using the accrual recalculation tool might adversely impact employees who have forced time off accrual on manual or special batches is a preparatory warning. The system functionality to force time off accruals on manual or special payrolls will be included in a future release.

To recalculate time off accruals:

  1. Enter or select the Time Off Type.

  2. Select the Accrual Schedule.

  3. Enter or select the Time Off Plan.

  4. Select Preview. The system processes the Time Off registers for that client, accrual schedule, and Time Off plan for the current plan year. (The date range automatically adjusts for each employee based on the year-end date in their register.)

  5. Enter a Comment on Adjustment that will display on the time off adjustment.

  6. Click Process Recalculation. A window opens that displays the processing steps.

  7. Click Close. A message displays, “Update Completed.” Click OK to continue.

  8. Click Download Report to view the time off accrual recalculation details on-screen. (You can save the file by clicking XLS.) The report displays on-screen. (You can also select Download Report to save this report.)

Note: Note the following:

  • Each employee has one written absence journal where the system writes the actual Time Off register once with the adjustment amount.

  • You can update accruals in the current plan year, but cannot close out the plan year or reset the YTD hours taken.

  • This process does not include carryover hours.

  • The adjustment effective date is based on the recalculation date.

  • Users whose role is set to INQUIRY for the Time Off Accrual Recalculation form cannot access this form.

You can use the Time Off Setup Workflow form to continue setting up in-progress time off plans or create new time off plans. (See Setting Up Time Off Plans.)

Understanding the Process Steps

The Time Off Setup Workflow process provides access to the following:

  • Step 1, Time Off Type: Begin the time off setup process using the Time Off Type form, which you can access from the Time Off Setup Workflow form (see Setting Up Time Off Plans). In this step, you will set the type for the time off plan. (See Setting Time Off Plan Type.)

  • Step 2, Set Up Plans: Create or update the employee time off accrual schedule, plan, pay, and portal configuration. (See Setting Up Employee Time Off.)

  • Step 3, Time Off Confirmation: Review the saved information from steps 1 and 2 and make updates. (See Confirming Time Off Plan Settings.)

  • Finalizing the information: After confirming that the information is correct click Finish Setup, which commits the saved time off plans to the system.
